# 入力ブロック（マウスを素直にする / パッド入力を無効化する）

`input-block.cfg` の中身を自分の `autoexec.cfg` の末尾に**貼り付けて使う**ブロックです。
（別ファイルにして `+exec` で読ませる方式は使わないこと。2024/2 に Respawn が `+exec` によるcfgチェーンを無効化している）

## 何が根拠か（このビルドの実測）

| 事実 | 出典 |
|---|---|
| マウス感度の計算は **`0x1409b6e10` の1関数**だけ | 静的解析（逆アセンブル） |
| その関数が読むcvar | `mouse_sensitivity` / `mouse_use_per_scope_sensitivity_scalars` / `mouse_zoomed_sensitivity_scalar_0..7` / `m_acceleration` / `mirror_main_scene` の5系統のみ |
| パッドの look 処理は **`0x1408a5350`** | 同上 |
| **パッド系cvar → マウス関数の参照は無い** | 静的xref（＝パッド設定がマウスの計算に直接入る経路は見つかっていない） |
| `m_acceleration != 0` でマウスデルタが sqrt 正規化される（＝加速） | 関数内の分岐 |
| `joystick` の文字列は **exe/同梱DLLに1つも存在しない** | 全文走査（0件）→ 静的登録cvarではなく、書いても効かない可能性が高い |
| `disable_mouselook` の文字列は存在する（exe `0x18bf570`） | 全文走査 |

## つまり何が「素直」に効くのか

実際のレバーは**マウス側の3つ**だけです:

- `m_acceleration 0` … 0以外だとマウス加速（sqrt正規化）が入る
- `mouse_use_per_scope_sensitivity_scalars 0` … 倍率ごとの感度スカラーを使わない
- `mirror_main_scene 0` … 左右反転なし

`mouse_zoomed_sensitivity_scalar_0..7` は既定が全て **1.0** なので、
`use_per_scope_sensitivity_scalars` が 0 の間は何を書いても結果は同じです（＝現状で既に「素直」な状態）。

## パッド側の行について（正直に）

- `gamepad_aim_assist_* 0` … パッドのエイムアシストを切る。**マウスには元々適用されない**ので、マウス勢には実質ノーオペレーション（パッド勢が使うと自分が不利になるだけ）
- `gamepad_ads_advanced_sensitivity_scalar_*` … 既定 1.0。小さくするとパッドADSが鈍くなる（パッド専用）
- `gamepad_aim_speed_ads_*` … 既定 -1（-1 は「ヒップ値の継承」を意味するセンチネル値）
- 静的解析では**パッド→マウスの経路は無い**ので、このブロックの実効性は
  「パッド入力が絡む環境（パッド検出・入力モード切替など）の揺れを消す保険」という位置づけ。
  効いているかどうかは体感でしか確認できないし、**差を感じなければ消してよい**（1行単位で戻せる）

## リスク

自分の入力設定を変えるだけで、他プレイヤーに対する優位は生まれません（視界・情報・判定に触る項目は含まない）。
