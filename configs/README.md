# autoexec.cfg（実測ベース）— 3バリアント

Apex Legends（EA app版 / `r5apex_dx12.exe`）の**実行ファイルを静的解析**して、
「このビルドのコードが実際に値を読むcvar」だけを選んで並べた autoexec.cfg です。
各行に **既定値 / 意味 / 副作用** のコメント付き。**1行ずつ消せば効かなくなる**のが方針です（全部ただのcvar）。

- 対象ビルド: `v3.0.1.28` / build `R5pc_r5-301_J28_CL11570498`
- 対象EXE: `r5apex_dx12.exe` sha256 `8bacf98c9409352b198ece7800a09141585a95eaf6f9dc003c0f6c1114ca3825`

## 収録バリアント

| フォルダ | 有効行 | 内容 | 向き |
|---|---|---|---|
| `full/` | **111** | 視覚カット全部入り（ブルーム/グレア/ブラー/露出/フォグ/マズルフラッシュ/揺れ）+ 性能 + 情報系6行 | カジュアル。コミュニティ標準＋α |
| `ranked/` | **105** | `full/` から**「情報・挙動に触る6行」だけ除外**（足音距離・ジップ音距離・フォグ・パーティクル倍速・切替クールダウン2本） | ランク。視覚カットは残しつつ「有利側の設定」を外す |
| `low-risk/` | **35** | **ゲーム自身がメニューから書く値のみ**（`settings.cfg`/`profile.cfg`/`videoconfig.txt` に実在するキー）＋ `fps_max` | 規約文言を厳密に気にする人 |

差分の実体（ranked と full の違い）:

```
fog_enable                    … 視界距離が伸びる
r_particle_timescale          … 煙・遮蔽が早く晴れる
cl_footstep_event_max_dist    … 足音の可聴距離を伸ばす（4000→5000）
rope_wind_dist                … ジップ音の可聴距離を伸ばす（1000→4000）
ordnanceSwapSelectCooldown    … グレネード選択の切替時間短縮
sidearmSwapSelectCooldown     … セカンダリ切替の時間短縮
```

## 設置手順

1. 使いたいフォルダから `autoexec.cfg` をゲームフォルダ直下へコピー（**管理者権限**）
   `C:\Program Files\EA Games\Apex\autoexec.cfg`
   （`r5apex_dx12.exe` と同じ場所。読み取り専用にしておくと事故らない）
2. **EAアプリの起動オプションに `+exec autoexec.cfg -novid` を追加**
   - これは**必須**。EXE内に `autoexec` という文字列が**存在しない**（実測0ヒット）＝エンジンは名前で自動実行しない
   - `+fps_max` は書かないこと（書くと設定ファイル側の値が負ける）
3. 元に戻す時は `autoexec.cfg` を消すだけ（ゲーム側の他の設定は触っていない）

## 何を根拠にしているか

- EXE全体から回収した cvar 台帳 **3,772件**（`cvar-ledger.tsv`）:
  - native readers **2,814**（コードが値を読むと確認）/ 読み手なし 929 / 動的登録 29 / `FCVAR_CHEAT` 288
- 「効く」の判定 = **このビルドの機械語が値を読む箇所を実測で確認**したものだけを採用（推測・他ゲームのコピペ禁止）
- 台帳外の項目（`videoconfig.txt` キー等）は別レイヤーとして扱い、`low-risk/` でその実在キーのみ使用
- 詳細: `CVAR-GUIDE.md`（全項目の意味）/ ルートの `notes/`（解析手順と証跡）

## ルール面（重要・正直に書いておく）

- **大会（ALGS）**: Year 2 のルールブックは `autoexec.cfg` をファイルとしては許可しつつ、**中身を5項目に限定**
  （`fps_max` / `mat_letterbox_aspect_goal` / `mat_letterbox_aspect_threshold` / `setting.csm_enabled 0` / カスタムレティクル）。
  現行の Year 5 / Year 6 ルールブックには **configファイルの節そのものが無く**、包括条項（unfair advantage / exploits）のみ。
  → 大会利用は自己判断で。
- **一般（カジュアル/ランク）**: EA利用規約に「EAが明示的に認めていないファイル変更」を禁止する文言がある。
  演出カット系cvarでのBAN確例は確認できていない（フォーラムの自称投稿のみ）が、**規約文言上はグレー**であることは明示しておく。
- **自動化（マクロ・外部ツール・cfgチェーン）は不可**。本リポジトリのcfgには含まれない（Respawnは2024/2に `+exec` のチェーンを無効化し、自動化を不正と明言）。

## 限界（正直に）

- **FPS等の効果数値は未計測**（このリポジトリは静的解析。効果はハード/ドライバ次第）
- 読み手未確認の929件・動的登録29件は**採用していない**（効果不明のため）
- 視覚的なビフォーアフター検証は含まない（各自の環境で1行ずつ試す前提）
- 非公開仕様のため、将来のアップデートで無効化されうる（その時は `grep` で無効行が判別できるよう [E]/[S]/[未] の印を付けている）

## 免責

自己責任で使用してください。ゲームファイルの改変・DLL配置・メモリ書き込み・外部ツールは一切行いません
（エンジン公式の `+exec` 経路のみ）。
